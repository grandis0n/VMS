В поле указывается исполняемый код, который будет выполнен методом «Выполнить()».
Вызываемые функции должны быть Экспортными быть расположены либо в общих модулях, либо в общих модулях расширений.
При написании кода доступны следующие переменные:
  • «Организация» - ссылка на организацию документа;
  • «Контрагент» - ссылка на контрагента документа;
  • «ДоговорКонтрагента» - ссылка на договор документа;
  • «СуммаДоходаРуб» - сумма проводки в руб.;
  • «СуммаДоходаВал» -  сумма проводки в валюте;
Кроме указанных переменных, можно использовать вложенные, ранее настроенные функции, выполнение вложенных функций выполняется по общему алгоритму.
Если, например, необходимо вывести значение реквизита параметра, возвращаемого другой функцией, следует указать идентификатор функции и через пробел или с новой строки, указать путь к требуемому реквизиту.
Например:
 «НаименованиеПорта .Страна.КодАльфа2» - функция вернет значение «Код Альфа 2», указанный в реквизите «Страна», для значения возвращаемого функцией «НаименованиеПорта».
где:
 - «НаименованиеПорта» - идентификатор функции, со способом получения значения «Мониторинговый параметр» и типом значения «Порты»;
 - «.Страна.КодАльфа2» - путь к реквизиту «Код альфа 2» справочника «Страны», указанного для элемента справочника «Порты»;
ВАЖНО! Идентификатор функции и путь к реквизиту должны быть разделены пробелом.

Кроме указанного способа, значение из примера можно получить, установив способ получения значения «Мониторинговый параметра», выбрать нужный параметр и, в поле «Путь к реквизиту», выбрать интересующий реквизит.
