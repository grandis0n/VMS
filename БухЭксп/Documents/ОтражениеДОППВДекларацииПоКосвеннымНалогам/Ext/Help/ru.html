Документ "Отражение ДОПП в декларации по косвенным налогам"

Документ предназначен для отражения документов о предстоящей поставке товаров (ДОПП) в разделе 4 декларации по косвенным налогам при импорте товаров из ЕАЭС.

Документ заполняется автоматически по введенным ранее документам о предстоящей поставке товаров.

При заполнении документа определяется текущее состояние поставки товара по ДОПП (анализируется наличие документа поступления), номер ДОПП в системе СПОТ, сумма обеспечительного платежа, внесенного по ДОПП.

В случае отмены поставки укажите соответствующее состояние поставки вручную.
