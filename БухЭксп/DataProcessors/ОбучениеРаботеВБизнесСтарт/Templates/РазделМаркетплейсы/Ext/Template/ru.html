Маркетплейсы

Многие продают товары на маркетплейсах. Например, на Ozon или Wildberries. Товары отгружаются маркетплейсу, а он доставляет их до покупателя и принимает оплату.

От маркетплейса можно получить данные о том, что продано. Эти данные вносятся в программу, чтобы рассчитать налоги и списать остатки товаров. Сделать это можно автоматически.

Подключение обмена с маркетплейсами

В программе можно подключить обмен с маркетплейсами. Это позволит автоматически загружать отчеты маркетплейсов и создавать документы.

Для подключения обмена с Ozon:

1. Откройте раздел Товары.

2. Перейдите по ссылке Маркетплейсы.

3. Нажмите кнопку OZON – Настройка подключения Ozon.

4. Заполните данные.

ClientID и API key необходимо получить в личном кабинете Ozon. Перейти в личный кабинет можно по ссылке настройки OZON.

5. Нажмите кнопку Записать и закрыть.

Для подключения обмена с Wildberries:

1. Откройте раздел Товары.

2. Перейдите по ссылке Маркетплейсы.

3. Нажмите кнопку Wildberries – Настройка подключения Wildberries.

4. Заполните данные.

Токен API нужно создать в личном кабинете Wildberries. Перейти в личный кабинет можно по ссылке Доступ к API.

5. Нажмите кнопку Записать и закрыть.

О подключении обмена с другими маркетплейсами читайте здесь.

Загрузка отчетов маркетплейсов

После того, как маркетплейс продал товары, он формирует отчеты о продажах. Отчеты автоматически загружаются в программу. При загрузке создаются документы Отчеты комиссионера о розничных продажах.

Загруженные отчеты можно проверить в разделе Товары – Маркетплейсы. Возможно после загрузки нужно будет дозаполнить документы.

Отражение услуг маркетплейсов

Маркетплейсы оказывают услуги: доставка, хранение, обработка возвратов и т.д. На свои услуги маркетплейс выставляет акт. Акт можно скачать в личном кабинете маркетплейса. В программе акт нужно отразить документом Поступление услуг: Акт, УПД.

Получение оплаты за товары

Маркетплейсы перечисляют оплаты за товары на расчетный счет. Они отразятся в программе при загрузке банковской выписки. Будут созданы документы Поступление на расчетный счет с видом операции Оплата от покупателя.
