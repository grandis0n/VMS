Кассовые аппараты

Для продажи товаров или оказания услуг физлицам вам понадобиться касса. С ее помощью формируются чеки с перечнем товаров и услуг, их количеством и ценой. Выдавать чеки покупателям нужно обязательно: на бумаге или в электронном виде. 

Также касса нужна для приема наличных и оплат по карте. Для приема оплат по карте необходимо заключить договор с вашим банком.

Продажи из кассы можно загрузить в 1С:БизнесСтарт. Далее по данным продаж в программе рассчитаются налоги. Список касс, которые рекомендуется использовать, смотрите здесь.

Подключение кассы

1. Откройте раздел Товары.

2. Перейдите по ссылке Настройки – Склады.

3. Откройте карточку склада. Выберите тип склада – Розничный магазин.

4. Перейдите по ссылке Добавить кассу.

5. Выберите Касса работает без подключения к компьютеру.

6. Выберите Обмен с сервисом Эвотор. Для обмена нужно получить токен в приложении 1С-Эвотор. Подробнее о приложении читайте здесь.

7. Заполните данные для подключения к кассе. Нажмите кнопку Записать и закрыть.

8. Для безналичных оплат нужно указать виды оплаты. Для этого нажмите кнопку Настроить виды оплаты.

9. Укажите виды оплат.

10. Затем выгрузите товары, услуги и цены в кассу. Нажмите кнопку Выгрузить прайс.

11. Нажмите кнопку Готово.

Загрузка продаж

Для загрузки продаж из кассы в 1С:БизнесСтарт:

1. Откройте раздел Товары.

2. Перейдите по ссылке Настройки – Склады.

3. Перейдите по ссылке Открыть список.

4. Перейдите по ссылке Загрузить продажи.

5. Выберите период. Нажмите кнопку Загрузить данные.

После загрузки будут автоматически созданы документы Отчеты о розничных продажах. В документах показывается, какие товары и услуги были проданы и возвращены за день.

Загрузка оплат по карте

Оплаты от покупателей по карте отражаются при загрузке банковской выписки. Будет создан документ Поступление на расчетный счет с видом операции Поступление по платежным картам.
